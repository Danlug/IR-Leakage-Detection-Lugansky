# IR Leakage Detection Lugansky

Совмещение фото с камеры и снимка тепловизора, чтобы видеть, где именно тепло/холод.

## Веб‑приложение (`index.html`)
Открыть: https://danlug.github.io/IR-Leakage-Detection-Lugansky/ (работает и на телефоне). Фото никуда не загружаются — всё в браузере.

1. «📷 Фото» и «🌡 Тепловизор» — выбрать пару снимков.
2. **Совмещение по точкам**: нажать заметную точку на фото (угол двери, край розетки, угол окна), затем ту же точку на тепловизоре. Точки можно тянуть, появляется лупа. 2 пары — сдвиг/масштаб/поворот, 3 — аффинное, 4+ — перспектива (учитывает, что снимки сделаны под разным углом). Лучше 6–8 пар по всему кадру.
3. **Проверка ровности**:
   - строка внизу: «проверка» — насколько каждая точка предсказывается остальными (в пикселях фото; зелёный < 0,4 % диагонали, жёлтый < 1 %, красный — хуже); «хуже всех стоит точка №…» — её стоит поправить;
   - на основном снимке от каждой точки идёт красная черта к месту, куда попала её пара — при ровном совмещении черт не видно;
   - режим **Шахматка** — клетки фото и тепловизора через одну: линии не должны ломаться на границах;
   - режим **Контуры** — голубые контуры фото и красные тепловизора, при совпадении белые; число «совпадение контуров» — больше значит ровнее.
4. **✨ Авто‑уточнение** — после точек доводит положение по контурам (мелкие сдвиги). С нуля, без точек, не работает: фото и тепловизор слишком разные.
5. Режимы просмотра: **Прозрачность** (ползунок), **Шторка** (линию тянуть), «⬇ PNG» — сохранить.

Совмещение запоминается как начальное для следующей пары. Ограничение: перспектива точна для плоских сцен (стена, шкаф); у предметов на разной глубине снятых с разных точек останется небольшой сдвиг.

Можно открыть пару по ссылке: `index.html?v=photo.jpg&t=thermal.jpg&mode=checker&align=1`.

Тест математики совмещения: `node test/align-core.test.js`.

## Скил (`skills/ir-leak-check/`)
`SKILL.md` — как Claude разбирает пары снимков (утечки тепла, сквозняки, влага, трубы, перегрев розеток).
`overlay.py` — те же наложения из командной строки:
```
python skills/ir-leak-check/overlay.py photo.jpg thermal.jpg --align '{"H":[...]}' --out result
```
(`--align` — JSON из кнопки «Копировать JSON»; на выходе `_blend`, `_swipe`, `_checker`.) Тест: `python skills/ir-leak-check/test_overlay.py`.

Установить скил в Claude Code: скопировать папку `skills/ir-leak-check` в `~/.claude/skills/`.

`samples/` (личные фото) в репозиторий не попадает.
