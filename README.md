# IR Leakage Detection Lugansky

Совмещение фото с камеры и снимка тепловизора, чтобы видеть, где именно тепло/холод.

## Два интерфейса

**Автор** — https://danlug.github.io/IR-Leakage-Detection-Lugansky/ (`index.html`)
1. «+ Новый отчёт», название (например «Масада 5»).
2. Для каждой пары: «+» в ленте пар → «📷 Фото» и «🌡 Тепловизор» → «Совмещение по точкам» → комментарий для клиента.
3. «💾 Сохранить и получить ссылку» — ссылка для клиента. Отчёт можно открыть снова из «Мои отчёты…» или по ссылке (в «Настройки и прочее»), поправить и сохранить: ссылка не меняется.

**Клиент** — ссылка вида `…/view.html#<id>.<ключ>` (`view.html`): предупреждение при каждом открытии (переключатель языка сверху, по умолчанию английский), галерея, снимок с режимами «Прозрачность» и «Шторка», вперёд/назад, комментарий. Языки: русский, английский, иврит. Совмещение менять нельзя.

### Температура
Клиент нажимает на снимок и видит примерную температуру («≈ 34.5 °C»). Она считается по цвету снимка тепловизора и шкале Max/Min: на ровных поверхностях ошибка около ±2 °C, на границах предметов — несколько градусов. Max и Min автор видит у каждой пары: они читаются с экрана тепловизора автоматически, их можно поправить. Без них клиент температуру не увидит. Модуль: `thermal-temp.js`, тест `node test/thermal-temp.test.js` (нужны `samples/` и Pillow). Разметка экрана задана для скриншотов текущего тепловизора 896×1195.

### Где хранятся отчёты
В репозитории [IR-Reports-Lugansky](https://github.com/Danlug/IR-Reports-Lugansky), **зашифрованными** (AES‑256). Ключ есть только в ссылке после `#` и никуда не отправляется, поэтому без ссылки отчёт не прочитать. Потерянную ссылку восстановить нельзя (она хранится в «Мои отчёты…» браузера, где отчёт создан).

### Токен для сохранения (один раз на каждом устройстве автора)
1. https://github.com/settings/personal-access-tokens/new
2. Token name: `IR reports`, Expiration: 1 год.
3. Repository access → **Only select repositories** → `Danlug/IR-Reports-Lugansky`.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. Generate token → скопировать → в приложении «Настройки и прочее» → вставить → «Запомнить токен».

Токен хранится только в этом браузере и даёт доступ только к хранилищу отчётов.

### Совмещение и проверка ровности
- Нажать заметную точку на фото, затем ту же на тепловизоре; точки можно тянуть (лупа). 2 пары — сдвиг/масштаб/поворот, 3 — аффинное, 4+ — перспектива. Лучше 6–8 пар по всему кадру.
- Строка внизу: «проверка» — насколько каждая точка предсказывается остальными (в пикселях фото; зелёный < 0,4 % диагонали, жёлтый < 1 %); «хуже всех стоит точка №…» — её поправить. Красные чёрточки на снимке — ошибка каждой точки.
- «✨ Авто‑уточнение» — после точек доводит по контурам; без точек не работает.
- Перспектива точна для плоских сцен; у предметов на разной глубине останется небольшой сдвиг.

Тесты: `node test/align-core.test.js`, `node test/report-core.test.js`, `node test/thermal-temp.test.js`.

## Скил (`skills/ir-leak-check/`)
`SKILL.md` — как Claude разбирает пары снимков (утечки тепла, сквозняки, влага, трубы, перегрев розеток).
`overlay.py` — те же наложения из командной строки:
```
python skills/ir-leak-check/overlay.py photo.jpg thermal.jpg --align '{"H":[...]}' --out result
```
(`--align` — JSON из кнопки «Копировать JSON»; на выходе `_blend`, `_swipe`, `_checker`.) Тест: `python skills/ir-leak-check/test_overlay.py`.

Установить скил в Claude Code: скопировать папку `skills/ir-leak-check` в `~/.claude/skills/`.

`samples/` (личные фото) в репозиторий не попадает.
