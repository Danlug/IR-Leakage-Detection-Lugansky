# IR Leakage Detection Lugansky

Совмещение фото с камеры и снимка тепловизора, чтобы видеть, где именно тепло/холод.

## Веб‑приложение (`index.html`)
Открыть: https://danlug.github.io/IR-Leakage-Detection-Lugansky/ (работает и на телефоне). Фото никуда не загружаются — всё в браузере.

1. «📷 Фото» и «🌡 Тепловизор» — выбрать пару снимков.
2. Галочка «Выравнивание»: тянуть тепловизор пальцем, масштаб двумя пальцами (или колесом/ползунком), поворот ползунком. Выравнивание запоминается для следующих пар.
3. Режимы: **Прозрачность** — ползунок меняет видимость тепловизора поверх фото; **Шторка** — слева тепловизор, справа фото, тянуть линию.
4. «⬇ PNG» — сохранить картинку.

Можно открыть пару по ссылке: `index.html?v=photo.jpg&t=thermal.jpg&mode=swipe`.

## Скил (`skills/ir-leak-check/`)
`SKILL.md` — как Claude разбирает пары снимков (утечки тепла, сквозняки, влага, трубы, перегрев розеток).
`overlay.py` — те же наложения из командной строки:
```
python skills/ir-leak-check/overlay.py photo.jpg thermal.jpg --align '{"x":0.5,"y":0.5,"w":1,"rot":0}' --out result
```
Тест: `python -c "import test_overlay as t; t.test_blend_and_swipe(); t.test_offset_outside_leaves_photo()"` в папке скила.

Установить скил в Claude Code: скопировать папку `skills/ir-leak-check` в `~/.claude/skills/`.

`samples/` (личные фото) в репозиторий не попадает.
